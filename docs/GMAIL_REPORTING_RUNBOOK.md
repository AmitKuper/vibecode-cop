# Gmail Reporting Runbook

## Overview

Game results are emailed to the course evaluator after bilateral consensus is
reached by both peers.  The Gatekeeper pipeline enforces safety invariants
before any real API call is made.

---

## Prerequisites (EXTERNAL_PENDING)

| Item | Status | Notes |
|------|--------|-------|
| Google Cloud project | EXTERNAL_PENDING | Create at console.cloud.google.com |
| OAuth 2.0 credentials | EXTERNAL_PENDING | Download as `credentials.json` |
| Gmail API enabled | EXTERNAL_PENDING | Enable in Google Cloud Console |
| OAuth scope | EXTERNAL_PENDING | `https://www.googleapis.com/auth/gmail.send` ONLY |
| Token file | EXTERNAL_PENDING | Generated by `scripts/gmail_auth.py` |

OAuth scope must be **gmail.send only** — never broader scopes (e.g., gmail.modify, mail.google.com).

## Reporting Preconditions

A real send may only proceed after **bilateral consensus** is verified:

1. Both cop and thief produce a `SignedResultAgreement`
2. `verify_bilateral_consensus(local, remote)` passes without raising
   `ResultConsensusError` (see `agent/audit/result_consensus.py`)
3. The body passed to `Gatekeeper.send()` must be a JSON-serialised signed result
   (body must start with `{`)

Plain-text bodies are rejected at the schema-validation step.

---

## Credential Security

- **Never commit** `credentials.json`, `token.json`, or any `*.token.json` file
- These paths are covered by `.gitignore`
- Store credentials in `secrets/gmail/` (also gitignored via `secrets/`)
- Rotate the OAuth token if it is ever accidentally exposed

## How to Run a Real Send (Manual Procedure)

> Tests use a fake sender — do NOT run real sends from pytest.

```python
from agent.gmail.gatekeeper import Gatekeeper
from agent.reports.gmail_send import load_oauth_credentials, gmail_api_send
from pathlib import Path
import json

creds = load_oauth_credentials(Path("secrets/gmail/token.json"))


def real_sender(to, subject, body, attachments):
    from email.mime.multipart import MIMEMultipart
    from email.mime.text import MIMEText

    msg = MIMEMultipart()
    msg["To"] = to
    msg["Subject"] = subject
    msg.attach(MIMEText(body, "plain"))
    return gmail_api_send(msg, creds)


gk = Gatekeeper(gmail_sender=real_sender)
mid = gk.send(
    idempotency_key="<game_uid>",
    game_id="<game_uid>",
    subject="Game Result: <game_uid>",
    body=json.dumps(signed_result.to_dict()),
)
print(f"Sent: {mid}")
```

## Pipeline Summary

```
Gatekeeper.send()
  1. Schema: body must start with "{"
  2. Idempotency: cached by idempotency_key
  3. Daily quota: max 20 sends
  4. Minimum interval: 5 s between sends
  5. Token bucket: 10 capacity, 0.1 tokens/s refill
  6. DOS detector: max 10/min, max 2 per game_id
  7. Circuit breaker: opens after 3 failures, 30 s recovery
  8. Concurrency semaphore: max 2 concurrent
  9. Retry with backoff: up to 3 attempts
 10. Gmail API call
```
